## 要解决的问题

把一批**真实论文**转成**带证据的节点与边**，并且能被查询、每条节点/边都能回到原文。
题面点名的四个判据：

| 判据 | 含义 |
|-|-|
| 抽得准 | 实体对应论文里真实出现的科研对象，不是模型凭常识补全的概念 |
| 连得对 | 关系类型、方向、适用条件与原文一致；不把共现/综述转述/推测当直接证据 |
| 对得齐 | 别名、缩写、大小写、同名冲突处理正确；不重复建点，也不错误合并 |
| 查得到、回得去 | 图谱能回答真实查询，且每个节点、每条边都能回到具体位置与原文片段 |

本题的输入修订还额外约束：**两篇独立论文**（不是同一篇的两种格式）进**同一张图**，
定位用**组织方 JATS 段落 ID**（不是 PDF 页码），跨篇**不得**把不同条件/样本/数值合成一个结论。

完整提炼见 [`docs/requirements.md`](docs/requirements.md)。
